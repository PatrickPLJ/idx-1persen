## Metodologi

- Data mentah: file `satu-persen` IDX/KSEI berisi semua investor dengan kepemilikan ≥1% per emiten (scripless + scrip).
- Nama investor dinormalisasi (variasi `PT`/`Tbk`/tanda baca) dan baris duplikat per investor-emiten dijumlahkan sebelum dibandingkan antar bulan.
- Persentase ditampilkan dengan pembulatan 2 desimal; Δ pp = selisih poin persentase.
- Perubahan < 0,05 pp diabaikan dari daftar kenaikan/penurunan.
- (F) = investor asing. Tanda "—" = data tidak dihitung untuk periode itu.
- 234 posisi di data Mei tidak memiliki keterangan lokal/asing di sumber, sehingga 5.333 + 1.594 < 7.161.
- Pasangan "ganti nama" dideteksi dari persentase nyaris identik (selisih < 0,1 pp); selisih kecil jumlah lembar masih mungkin (mis. CFIN berkurang 10.000 lembar).
